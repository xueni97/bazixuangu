# 八字选股APP（渊海子平命理选股）

基于《渊海子平》天干地支决策模型 + 股票名称五行属性的选股工具，输出周/月/日方向买点。

## 双端使用

### 电脑端（浏览器大屏版）

1. 双击 `启动选股工具.bat`（自动起服务并打开浏览器）
2. 或手动：`..\.venv\Scripts\python.exe server\app.py` 后访问 http://127.0.0.1:5175
3. 桌面宽屏自动切换双栏工作台：评分排行 + 五行分布图 + 数据同步面板

首次使用点「更新数据」拉取全市场快照（~5400只，含沪深创/北交所）。服务启动时当日无快照会自动后台同步。

### 手机端（Android APP）

1. 从 GitHub Actions 下载 APK（`bazixuangu-apk-v*` 工件）安装
2. 日/周/月方向、买点信号完全离线可用
3. 「股票扫描」需电脑服务在线：手机与电脑连同一WiFi，APP右上角设置填入电脑地址（服务启动时控制台会打印，如 `http://192.168.x.x:5175/api`）

### 开发调试

```bash
npm install
npm run dev          # 前端 :5174（/api 代理到 :5175）
npm run build        # 构建到 dist/（后端托管大屏版用这个）
npm run android:sync # 构建+同步到Android工程
```

## 架构

- 前端：Vue 3 + Vite + Vant，核心命理逻辑在 `src/core/`（纯JS，离线可用）
- 后端：Flask（`server/`），数据同步 + API + 静态托管
- 数据：akshare 全市场快照 → SQLite `stock_spot` 表；命理评分只依赖股票名称五行

## 命理模型说明

以当日四柱为"市场命盘"：判日主旺衰（得令/得地/得势）→ 定用神忌神（扶抑+调候）→ 股票名称五行匹配评分。**仅供国学研究与娱乐参考，不构成投资建议。**
